# GameToolkit2025 Seafloor Revival

Seafloor Revival is a Unity 2D underwater building game project.

## Open the project

Use Unity 6000.5.9f1 and open this repository as a Unity project. Allow Package Manager to restore the dependencies, then open `Assets/Scene/GameScene.unity`.

The project uses the Universal Render Pipeline, AI Navigation, and NavMeshPlus. Package versions and the Git dependency revision are recorded in `Packages`.

## Import status

This project was imported from a Tuanjie asset package. The scene format and legacy TextMesh Pro example code were adapted for Unity 6. Scripts compile and the main scene loads.

The original package is missing the scripts referenced by the population UI and furnace. Those references are preserved. Complete gameplay has not been verified. See `IMPORT_NOTES.txt` for details.
